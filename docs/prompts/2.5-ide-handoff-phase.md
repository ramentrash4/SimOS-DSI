# PROMPT FASE 2.5: IDE HANDOFF & CONTEXT LOADING

**SYSTEM ROLE & PHASE SHIFT**
Ini adalah sesi IDE (AGV IDE). Anda baru saja "terbangun" di lingkungan proyek ini. Tugas pertama Anda bukanlah menulis kode, melainkan melakukan sinkronisasi memori (*Context Loading*) dengan semua keputusan arsitektur yang telah disepakati oleh Agen Perencana sebelumnya.

**LANGKAH WAJIB (FORCED READING)**
Gunakan *tool* Anda (seperti `view_file` atau `read_file`) untuk membaca dan menyerap seluruh isi dari 6 dokumen inti yang berada di dalam folder `/docs` (atau subfolder di dalamnya):
1. `PRD` (Product Requirements Document)
2. `SRS` (Software Requirements Specification)
3. `SDD` (System Design Document)
4. `UI_FLOW` (UI/UX Flow)
5. `DESIGN.md` (Linter Visual Mutlak)
6. `TASK_BREAKDOWN` (Daftar Tugas)

**ATURAN INISIATIF BERSYARAT (PROACTIVE IMPROVEMENT):**
- Dokumen-dokumen di atas adalah patokan utama Anda. `DESIGN.md` adalah hukum tertinggi untuk visual.
- **Namun**, Anda tidak dibatasi menjadi robot kaku. Jika saat membaca dokumen Anda menemukan celah logika, peluang optimasi, atau ide perbaikan arsitektur/UI yang jauh lebih elegan: Anda **DIPERBOLEHKAN dan DIDORONG** untuk proaktif memberikan saran.
- **Syarat Mutlak:** JANGAN langsung mengeksekusi ide baru tersebut! Hentikan alur kerja sejenak, sampaikan inisiatif/ide Anda kepadaku, ajak saya berdiskusi, dan implementasikan *HANYA* setelah saya memberikan persetujuan eksplisit.
- Patuhi aturan *Git Workflow* spesifik yang tertulis di dalam file `TASK_BREAKDOWN`.

**LANGKAH PERTAMA ANDA:**
Jangan menulis kode apa pun dulu. Baca keenam dokumen tersebut secara menyeluruh menggunakan *tools*. Setelah selesai membaca semuanya, balas *prompt* ini HANYA dengan:
*"Sinkronisasi Memori Selesai. Saya telah menguasai PRD, SRS, SDD, UI/UX, Desain, dan Task Breakdown proyek ini. Silakan kirimkan Prompt Fase 3 (Eksekusi) untuk mengatur mode kerja kita."*
